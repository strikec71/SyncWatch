# Свой сервер синхронизации SyncWatch за 5 минут

SyncWatch не гоняет через сервер видео — только маленькие команды плеера
(play / pause / перемотка / скорость). Поэтому «сервер» — это крохотный
ретранслятор на **Cloudflare Workers**, который ты поднимаешь в свой **бесплатный**
аккаунт. Свой сервер = свой бесплатный трафик, не зависящий ни от кого.

> Публичного сервера «по умолчанию» у SyncWatch нет — каждый круг друзей поднимает
> свой. Это и делает раздачу бесплатной и приватной.

---

## Что понадобится

- **Аккаунт Cloudflare** — бесплатный, регистрация на <https://dash.cloudflare.com/sign-up>.
  Карта и домен НЕ нужны.
- **Node.js 18+** — <https://nodejs.org> (LTS). Проверить: `node -v`.
- Папка с кодом SyncWatch (эта репа).

---

## Шаги

### 1. Войти в Cloudflare из терминала

```bash
cd server
npm install
npx wrangler login
```

Откроется браузер — подтверди доступ. Это разовое действие.

### 2. Задеплоить релей

```bash
npm run deploy
```

В конце Wrangler напечатает адрес вида:

```
https://syncwatch-signal.<твой-субдомен>.workers.dev
```

Скопируй его. `<твой-субдомен>` — это твой личный workers.dev-субдомен
(Cloudflare предложит выбрать при первом деплое).

### 3. Превратить адрес в адрес сервера SyncWatch

Замени `https://` на **`wss://`** (это WebSocket-схема). Получится:

```
wss://syncwatch-signal.<твой-субдомен>.workers.dev
```

Это и есть твой адрес сервера. **Порт и путь дописывать не нужно** — расширение
само добавит `/room/<код>`.

### 4. Вписать адрес в расширение

1. Открой островок SyncWatch на любой странице с видео.
2. Раздел **«Ещё» → поле «Сервер»** — вставь `wss://…workers.dev` из шага 3.
3. Задай код комнаты (или нажми **«Создать»**) и **«Войти»**.

Готово — ты на своём сервере.

---

## Как позвать друзей

Друзьям **не нужно** ничего деплоить и даже вписывать адрес вручную —
инвайт-ссылка несёт твой сервер внутри себя.

1. В островке нажми **«Приглашение»** — скопируется ссылка вида
   `https://…workers.dev/join#r=<код>&s=<твой-сервер>`.
2. Отправь её другу (мессенджер, что угодно).
3. Друг с установленным расширением открывает ссылку → расширение **само**
   сохраняет твой адрес сервера и код комнаты и подключается.

После первого раза адрес у друга сохранён — дальше можно кидать даже короткую
**«Ссылку на видео»** (`…#syncwatch=<код>`), она подхватит уже сохранённый сервер.

> Друг без расширения увидит страницу-заглушку с предложением его поставить —
> это нормально, вход делает именно расширение, а не сайт.

## Проверка, что сервер жив

Открой в браузере (уже `https://`, без `wss`):

```
https://syncwatch-signal.<твой-субдомен>.workers.dev
```

Должно ответить `SyncWatch signaling server`. Если да — релей работает.

## Про нагрузку и трафик (коротко)

- Комнаты **изолированы** по коду: у каждого кода — свой отдельный объект-комната,
  до **10 участников**. Сообщения одной комнаты никогда не попадают в другую.
- Сервер платит Cloudflare только за **время, пока в комнате есть подключённые**.
  Пустая комната ничего не стоит.
- Чтобы забытая вкладка на паузе не жгла лимит впустую, расширение **само
  отключает** сессию после **1,5 часа полного простоя** (никто не смотрит и не
  жмёт кнопки). Возврат — обычный «Войти».
- Бесплатного тарифа Cloudflare с запасом хватает на компанию друзей и киновечера.
  Если однажды упрёшься — это апгрейд на стороне Cloudflare (Workers Paid, ~$5/мес),
  расширение менять не нужно.

## Обновить / переразвернуть

Меняешь код сервера (`server/src/…`) → снова:

```bash
cd server
npm run deploy
```

Адрес остаётся тот же — друзьям ничего перевыдавать не надо.

## Если что-то не так

| Симптом | Причина / что делать |
|---|---|
| `wrangler: command not found` | Запускай через `npx wrangler …` из папки `server` |
| Деплой просит выбрать субдомен | Это разовая настройка workers.dev — выбери любое имя |
| В расширении «Не задан адрес сервера» | Поле «Сервер» пустое — вставь `wss://…` из шага 3 |
| Подключение не встаёт | Проверь схему: должно быть **`wss://`**, а не `https://`/`ws://` |
| Друг открыл ссылку, но не подключился | У друга должно быть установлено расширение SyncWatch |
| Хочу проверить локально | `npm run dev` поднимет `ws://localhost:8787` (адрес сервера — `ws://localhost:8787`) |
