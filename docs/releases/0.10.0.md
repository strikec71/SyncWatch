# SyncWatch 0.10.0 — English & Russian

SyncWatch now speaks English as well as Russian. Open **Style → Language** and
choose English, Русский or Browser language. The selection is saved and updates
open panels without leaving the room or losing your chat draft.

- Full English panel, room roles, chat controls, friends, invitations, quick messages,
  connection notices, error hints and fullscreen labels.
- Browser-language mode uses Russian for Russian locales and English otherwise.
- Quick phrases render in each recipient's language; names and free-text messages
  remain exactly as sent.
- Language choice survives reload/remount and appearance reset. Existing room,
  relay, identity, friends and appearance settings are preserved.
- Localized extension metadata, English/Russian server invitation and privacy pages,
  English documentation, updated store descriptions and five current screenshots.
- Retains the customizable Glass Lounge interface introduced in 0.9.0: themes,
  gradients, panel sizes, opacity, reduced motion and compact launcher.

Requires Chrome 120+. The release uses the verified SyncWatch Cloudflare relay;
existing custom relays are retained. No new permissions, runtime dependencies,
remote code, analytics or translation services. Server 0.4.1 changes public pages;
room/presence protocols remain compatible.

Validation: extension TypeScript and 356 unit/regression checks, server TypeScript
and 73 checks, 34 Chromium fullscreen checks and 22 design/localization checks.
These source-module fixtures do not replace installed-extension acceptance on
current live video sites.

The GitHub release and Chrome Web Store approval are separate. The owner requested
store review with automatic publication after approval; see STATUS.md for the
confirmed state. Until approval/distribution, existing store users keep their
current version. The ZIP and SHA256SUMS attached to this release are the store
submission package; screenshots contain clearly marked illustrative room data.
