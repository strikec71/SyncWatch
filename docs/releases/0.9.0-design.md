# SyncWatch 0.9.0 — Glass Lounge

The in-page interface now combines a lavender/rose glass gradient, a 52px launcher,
four compact navigation tabs, a conversation layout and quiet fullscreen notices.
It is implemented in the existing TypeScript/closed Shadow DOM UI without new
runtime dependencies, remote assets, permissions, or a React migration.

Appearance settings persist across pages and remounts: dark/light/system theme,
Lounge/Aurora/Ocean/Rose gradients, comfortable/compact size, glass opacity,
motion, and left/right placement. Reset affects appearance only. The system's
reduced-motion setting always takes precedence. The header remains draggable;
resizing and expanding the launcher keep the panel inside the viewport.

Room status, participant count and management roles remain visible above the
navigation. The mini launcher retains connection and unread indicators. Chat
keeps drafts and renders names/messages as text. Connection settings are under
the room tab, separate from presentation controls.

Validation: `npm run verify` in extension; `npm run test:browser` runs the existing
34 real Chromium fullscreen checks plus the new design acceptance suite.
`docs/audit/design-check.mjs` checks real UI modules with only extension transport
replaced; screenshots/results are generated in ignored `docs/audit/design/`.
These fixtures do not establish acceptance of the installed extension on every
live player/site.

The release candidate is on `codex/glass-lounge-redesign`. The owner requested
replacing the pending Chrome Web Store 0.8.0 review with this 0.9.0 package.
The original 0.8.0 tag is preserved. Production server 0.4.0 is compatible and
does not need another deployment for this UI update. Record confirmed review
status in `STATUS.md`; do not equate package upload with successful submission.
