# SyncWatch 0.8.0 — Chrome

Обновление существующей карточки Chrome Web Store. Требуется Chrome 120+ и сервер SyncWatch 0.4.0.

- Исправлена работа панели, колеса и сообщений в fullscreen, включая внешние iframe. Для нативных видеоконтролов добавлена кнопка ⛶; чат и колесо доступны мышью.
- Добавлен текстовый чат до 200 символов. Исправлены черновики, ошибки отправки и автопауза без сброса позиции/скорости.
- Исправлены буферизация, реклама, поздний вход, порядок перекрестных команд, восстановление соединения и независимые сессии вкладок.
- Исправлены приглашения и статусы друзей: подписи запросов, отдельные токены приглашений, подтверждения доставки и отзыв видимости.
- Обновлены политика конфиденциальности, проверки и зависимости. Оставлена только Chrome-сборка.

ZIP `syncwatch-chrome-0.8.0.zip` загружается в существующий товар. Контрольная сумма — в `SHA256SUMS`. Release ZIP содержит только собранные файлы расширения; исходники сервера доступны в архиве исходников этого тега.

Этот GitHub Release остается черновиком до завершения выпуска. Его наличие не означает деплой сервера, отправку на модерацию или доступность 0.8.0 в Chrome Web Store. Проверять фактические результаты jobs и статус товара в кабинете. `/version` сервера продолжает объявлять 0.6.0 до доступности нового магазинного обновления.

Старые ссылки друзей из промежуточной реализации нужно создать заново. История чата и черновики хранятся в памяти сессии. Сервер видит команды, URL, имя и чат; сквозное шифрование не заявляется. Результаты аудита и границы браузерной приемки — в `docs/FIX-RESULTS.md`.
