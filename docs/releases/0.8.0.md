# SyncWatch 0.8.0 — Chrome (historical)

Chrome 120+; server 0.4.0. This updated the existing store item, not a new extension.

- Improved panel, chat wheel and messages in fullscreen, including external frames
  and a mouse-accessible native video fullscreen control.
- Added 200-character text chat, preserved drafts/errors and safe quick-message pause.
- Bundled the verified SyncWatch Cloudflare relay for new installs while preserving
  existing custom servers.
- Fixed buffering/ads, late join, simultaneous commands, reconnect and tab isolation.
- Hardened friend invitations/presence with signatures, separate tokens, delivery
  acknowledgements and revocation.
- Updated privacy, validation and dependencies; retained Chrome packaging only.

The reviewed ZIP was syncwatch-chrome-0.8.0.zip with SHA256SUMS; server sources
belong to the corresponding tag. The GitHub draft did not itself establish store
approval or production availability. The pending 0.8.0 store review was later
withdrawn in favor of 0.9.0. See STATUS.md for current release state.

Old friend links from the intermediate unsigned implementation need replacement.
Chat/drafts remain in session memory; relayed contents are not end-to-end encrypted.
