# Audit of SyncWatch 0.6.0 — historical record

Audit date: 24 October 2026 (Asia/Qyzylorda). Revision: b603e0c.
This report describes the old Chrome/Firefox implementation, not current 0.10.0.
The complete original Russian report, detailed reproductions and original line
references are preserved in [the archive](archive/ru/AUDIT-2026-10-24.md).
Current verification and limitations are in [FIX-RESULTS.md](FIX-RESULTS.md).

The audit found a viable architecture with unreliable transitions between manual
pause, buffering, ads, late joins, reconnects, content changes and simultaneous
commands. Passing narrow unit tests did not establish correct shared viewing.

## Historical evidence

| Check | Original result |
|---|---|
| Extension tests | 200 passed in 8 files |
| Server tests | 36 passed in 2 files |
| TypeScript and Chrome/Firefox packages | Passed/built for 0.6.0 |
| Targeted defect regressions | 19 reproduced incorrect behavior |
| Chromium HTMLVideoElement checks | 5 reproduced controller defects |
| Local Worker and real WebSocket clients | Confirmed room behavior and three trust-boundary defects |
| Dependency audit | 7 extension / 10 server findings, mostly development tooling |
| Installed extension and live target sites | Not verified in that environment |

Targeted checks were chosen for known defects, not a random sample of product
behavior. Browser harnesses used the real controller/video with substituted browser
transport. Real ads, Firefox, installed builds and production were not validated by
those checks. No product code was changed during the original audit.

## Findings index

| ID | Priority | Historical problem |
|---|---|---|
| AUD-01 | P1 | Buffer/ad holds did not actually pause/resume correctly |
| AUD-02 | P1 | Multi-participant holds were aggregated and cleared incorrectly |
| AUD-03 | P1 | Last-writer-wins did not converge for simultaneous commands |
| AUD-04 | P1 | Late/rejoining participants did not receive host speed |
| AUD-05 | P1 | Remote content commands affected a local advertisement timeline |
| AUD-06 | P1 | Global defaults broke independence of tab sessions |
| AUD-07 | P1 | Watchdog could disconnect a healthy transport |
| AUD-08 | P1 | Service-worker suspension recovery was incomplete |
| AUD-09 | P1 | Ready iframe/source replacement could miss synchronization |
| AUD-10 | P1 | Pause exception bypassed seek restrictions |
| AUD-11 | P1 | Server allowed stale rooms and excessive messages |
| AUD-12 | P1 for public relay | Short room names were insufficient access secrets |
| AUD-13 | P2 | Invitations and first launch had dead ends |
| AUD-14 | P1 | Navigation scope exceeded viewing and privacy disclosure |
| AUD-15 | P2 | Background DOM scans continued outside rooms |
| AUD-16 | P2 | Updates/docs promised absent features |

These issues led to ordered revisions/ACKs, desired-state/hold separation, active
frame readiness, session isolation, lifecycle limits, explicit invitations, origin
restrictions and truthful privacy/release reporting. Read the original archive for
per-finding evidence; do not interpret this historical index as a fresh regression
result or guarantee that every current website is supported.
